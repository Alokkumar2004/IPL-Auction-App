# 🏏 IPL Auction App

A full-stack **IPL-style Player Auction Application** built using **React**, **Firebase**, and **Framer Motion**.  
It simulates a real-time IPL auction experience with player bidding, team purse tracking, and dynamic animations.

---

## 🚀 Features

- 🎯 **Live Player Auction** — Bid on players one by one in a real-time flow.
- 💰 **Dynamic Bidding System** — Teams bid using a virtual purse with automatic validations.
- 🏏 **10 IPL Teams** — Each team can acquire players up to a defined limit.
- ⏱ **Auction Timer** — Auto-sells players when the timer hits zero.
- ⚡ **Round Transition Animation** — Smooth transition between Main and Unsold Rounds.
- 🔄 **Unsold Round Replay** — Unsold players reappear for another round of bidding.
- 🏁 **Auction End Summary** — Displays the final team compositions and spending.
- 📊 **Team Stats Dashboard** — Responsive grid showing all 10 teams (5 per row × 2 rows).
- 🎨 **Modern UI** — Gradient background, glowing animations, and interactive effects with Framer Motion.
